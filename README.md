## 🚀 Qanday Ishga Tushiriladi?

### 1. Dasturni rivojlantirish (Dev server):
```bash
npm run dev
```
Brauzerda `http://localhost:5173` manzilini oching.

### 2. Ishlab chiqarish uchun yig'ish (Build):
```bash
npm run build
```

### 3. Tayyor saytni ko'rish (Preview):
```bash
npm run preview
```
